# 05 — Modo Local

## Objetivo
Permitir FINNOS sem Conta FINNOS e sem armazenamento financeiro obrigatório nos servidores FINNOS.

## Regras
- dados ativos permanecem no dispositivo;
- backup é opcional;
- iCloud Drive/Google Drive não transformam automaticamente o usuário em Conta FINNOS;
- importação/exportação deve funcionar no modo local;
- perda/limpeza do armazenamento local pode causar perda de dados sem backup; a UI deve comunicar isso claramente.

## Pendente
Definir tecnologia definitiva de persistência local e estratégia de migração/versionamento do schema antes de considerar o modo pronto para dados reais.
